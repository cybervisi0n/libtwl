# libtwl
Drop-in replacement for TwlSDK that targets Nintendo DS(i), PC, and other platforms.

## OBSOLETED: This is being merged into [libntr](https://github.com/cybervisi0n/libntr), gated by conditional compilation

libntr makes it easier to port Nintendo DS(i) games to PC and other platforms by handling the logic for common libraries used by nearly all Nintendo DS(i) games.
